# 首步纠偏两强度实验：复核与结果分析

复核日期：2026-10-21。HunyuanVideo T50 → AccVideo S5，首步介入一次，λ=0.1/0.3；沿用既有 48 条 prompt 和 seed=2026101901。

**结论：两组都使主体一致性测试均值小幅高于原学生，且保留约 5.72× 的相对教师推理速度优势；多物体符合度均值却下降。λ=0.3 的主体均值增益较大，同时多物体退化和运动变化也更明显。此次结果支持主体维度的有限收益，尚未实现两个质量目标同时改善。**

- 共核对 192 个原文件/归档文件哈希；96 条视频的现有文件与生成时通过解码检查的文件一致，均为 1280×720、129 帧、24 FPS。48 对两强度的初始条件、重加噪及教师查询一致；未发现错配、缺项或中断产物混入。
- 冻结的代码、配置、H2 基线与资源元数据未变。逐样本均值、配对计数、参考区间和分项耗时复算与自动报告差为 0。所有已记录控制器及 worker 已退出。

## 2.1 新增固定统计：原教师占优 prompt 的纠偏变化

按研究者要求，每次质量升降总结同时报告完整任务库和“原教师更好”的子集。对每项质量指标 m 分别定义：

\[
\mathcal P_m^+=\{p:y^{T50}_{p,m}>y^{S5}_{p,m}\},\qquad
\Delta^{T>S}_{m,\lambda}=\frac{1}{|\mathcal P_m^+|}\sum_{p\in\mathcal P_m^+}(y^{corr,\lambda}_{p,m}-y^{S5}_{p,m}).
\]

使用 H2 原始未舍入分数和原 seed=2026101901；两种 λ 使用同一子集，筛选不依赖纠偏后的分数。不同质量指标各自确定子集，不要求其 prompt 取交集。

| 指标 | 原教师占优 prompt 数 | 教师均值 | 学生均值 | λ=0.1 均值 | λ=0.3 均值 |
|---|---:|---:|---:|---:|---:|
| 主体一致性 | 21 / 32 | 95.6557 | 92.8566 | 92.9234 | 93.1105 |
| 多物体符合度 | 8 / 16 | 83.5938 | 31.2500 | 34.3750 | 35.1562 |

| 指标 | λ | 纠偏−学生均值 | 提升 / 持平 / 下降 |
|---|---:|---:|---|
| 主体一致性 | 0.1 | +0.06683 分 | 7 / 0 / 14 |
| 主体一致性 | 0.3 | +0.25392 分 | 6 / 0 / 15 |
| 多物体符合度 | 0.1 | +3.12500 分 | 3 / 3 / 2 |
| 多物体符合度 | 0.3 | +3.90625 分 | 3 / 2 / 3 |

**本次两个质量指标在各自原教师占优子集上，两种强度的平均变化均为正。**这为“已有教师优势条件下，推理纠偏能够带来平均收益”提供了直观的样本层面支持；多物体由全库负收益转为该条件子集正收益，尤具解释价值。主体子集内仍有较多样本下降，平均收益由部分较大提升贡献，逐条数量如表。
dynamic_degree 不按数值更高定义“教师更好”。补充观察主体教师占优的 21 条：教师、学生和两组纠偏均为 20/21 条判定有运动，逐条判定均未变化；多物体库没有额外计算动态指标。
该项是基于既有基线的补充条件统计，与完整 32/16 条主结果并列保留；不删除其余样本，不改写全库多物体均值下降的结论。子集名单与全部数值保存在 `REVIEW.json` 的 `teacher_advantage_subsets` 字段。

## 3. 逐样本表现与教师优势的关系

| 指标 | λ | 高于学生 / 相同 / 低于学生 |
|---|---:|---|
| 主体一致性 | 0.1 | 15 / 0 / 17 |
| 主体一致性 | 0.3 | 12 / 0 / 20 |
| 多物体符合度 | 0.1 | 3 / 10 / 3 |
| 多物体符合度 | 0.3 | 3 / 8 / 5 |
| 动态视频比例 | 0.1 | 0 / 32 / 0 |
| 动态视频比例 | 0.3 | 0 / 31 / 1 |

主体均值为正并不代表多数 prompt 获益：λ=0.1 为 15/32 条提升，λ=0.3 为 12/32 条提升，增益由部分较大改善样本支撑。两组增益最大的三条均为 MOTION_13（堵车）、MOTION_05（卡车减速）、MOTION_24（公园中的猫）。

**多物体的关键现象：教师在全库均值更好，但并非每条 prompt 都更好。**以下为事后分组解释，完整 16 条主统计不变，不据此删除或重选样本。

| H2 原有逐 prompt 表现 | 数量 | λ=0.1 平均变化 | λ=0.3 平均变化 |
|---|---:|---:|---:|
| 教师高于学生 | 8 | +3.1250 分 | +3.90625 分 |
| 教师与学生相同 | 5 | 0 分 | −1.2500 分 |
| 学生高于教师 | 3 | −12.5000 分 | −18.7500 分 |

例如 OBJECTS_06（叉子与盆栽），教师/学生为 100/43.75，纠偏后为 62.5/75，存在明显正收益。相反，λ=0.1 在 OBJECTS_13（三明治与书）上从学生 100 降至 62.5，而教师为 0；λ=0.3 在 OBJECTS_16（吹风机与牙刷）上从学生 93.75 降至 37.5，而教师为 6.25。这些较大负变化抵消了其他样本的收益。
这一相关性提示，固定首步纠偏同时存在正向帮助和负向影响。它不证明教师某次局部预测必然正确或错误，也不能据此采用事后挑样本的效果结论。

## 4. 运动变化

λ=0.1 与学生逐条动态判定完全相同：27/32；λ=0.3 为 26/32，唯一从有运动变为无运动判定的是 MOTION_19（人吃汉堡）。其主体一致性提高约 0.5061 分。
作为解释性核查，其余 31 条的主体一致性平均变化仍为 +0.1844 分，因此这一条动态分类变化不能单独解释 λ=0.3 的全部主体均值收益。此核查不替换原 32 条统计。dynamic_degree 是二值判定，相同判定不等于实际运动幅度完全相同；不设置接受阈值，由研究者判断取舍。

## 6. 研究判断与后续方向

1. **已有正向证据：**完整面板上主体一致性均值小幅提高、相对教师速度优势保留；在各质量指标原教师占优的固定子集上，主体一致性与多物体两项的两强度均值均提升，补充支持教师优势条件下的纠偏收益。
2. **尚未实现的部分：**多物体全库均值没有提升；λ=0.3 也带来一次运动分类下降，不能概括为整体质量全面提高。
3. **两强度取舍：**λ=0.3 的主体均值更好；λ=0.1 的多物体损失更小且动态判定不变，二者不存在所有目标上的统一胜者。
4. **建议，尚未执行：**优先保持当前 prompt/seed 与指标，研究介入时机是否改善上述取舍。现有两目标已经提供了可解释的正负信号，补充 prompt 或指标可以后置；不根据本轮结果删除学生原本更强的样本。

本轮属于同一既有面板上的算法比较，不外推为所有 prompt 或其他 seed 上的结论。参考区间和完整逐样本值保留，不额外设为研究推进门槛。
