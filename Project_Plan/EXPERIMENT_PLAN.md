## 4. 生成与评测口径

保持 H2 设置：1280×720、129 帧、24 FPS、shift=7、embedded guidance=6、external CFG=1；原生 Hunyuan DiT 与 Euler，DiT BF16、步间 FP32、VAE FP16。沿用 H2 模型资源和公共组件，不下载、不转换保存额外大权重、不量化或加入缓存加速。

纠偏学生保持五次学生预测，增加一次教师预测，采用“学生干净端点→独立重加噪→教师端点→插值→继续学生”流程。Flow 代数适配是推导，质量改善是待检验假设；不把 Flow velocity 当作 epsilon。

三项指标沿用H2评测源码、权重和预处理。**以每项完整任务库的均值、相对S5/T50的变化及固定λ下介入位置比较为主线**；逐prompt差值和升降数量作补充，不新增综合评分或跨零准入门槛。dynamic_degree仅如实报告，是否可接受由研究者判断。

速度采用真实计时；学生采样、教师查询、纠偏计算、VAE、模型切换和传输纳入同口径比较，加载、预热和视频导出另列。不按 50/5 推算加速，不把多卡并发当作算法收益。复用 H2 历史计时应注明采集时期不同。

教师优势/劣势/持平分层保留为补充CSV/JSON，不作为主要分析重点、prompt筛选规则或准入条件。主报告对比第1–4步×三个λ的完整任务库均值与真实耗时。同一λ并非等latent扰动，结合已有幅度记录解释；复用结果保留已披露的单条逐位差异，不擅自替换或重跑。
