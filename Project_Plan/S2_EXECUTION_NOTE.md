# S2 执行口径

**已完成：96 条视频、576 个分数；五质量指标 0/5 通过，S3 未开始。**下文保留生成前执行约定；运行事件和结果见 S2 阶段记录及分析报告。

用户已授权正式 S2，止于教师资格判断，不进入 S3。原始计划的六指标、16 prompts × seeds 42/1234/2026、五质量维度 99% 区间、预设目标优先级保持不变；dynamic_degree 不设数值容许界。

冻结排程见 `S2_EXECUTION.json`，远端执行快照为 `runs/s2_20261016/execution.json`。48 对共 96 条正式视频，各类内 T50 先运行 / S4 先运行各六对，各 worker 两种先后顺序数量差不超过一。每对在同卡顺序执行，共用同一 CPU FP32 源噪声与相同正向条件；三个 seed 不变。按当前空闲卡分配七个独立单卡 worker，CPU 各限制四线程；这不是七卡模型并行。GPU 7 的已有任务不使用。

每个 worker 在正式样本之前，使用独立的 S1 prompt/seed 分别完成一次完整 T50/S4 去噪及 VAE 预热，不导出或评测预热视频。两模型、同一 T5 和 VAE 共同常驻单卡，不 offload；此方式已经过 S1 显存验收。峰值显存含另一组模型的驻留占用，不能当作单独部署的最小显存。

主计时为 CUDA 同步的去噪 + VAE。去噪循环不写文件、不查询 nvidia-smi、不逐步同步/做张量统计；另一个 CPU 线程每十秒记录卡占用和进度，其小量监控开销不扣除。文本条件每对编码一次，两组复用；固定负向条件每 worker 缓存一次，仅教师使用。模型加载、源噪声传输/采样器初始化、文本编码、输出编码与完整解码核查分别记录；不把主计时冒充从进程启动到成片的端到端延迟。

S2 速度统计在看结果前固定为 `median(T50)/median(S4)`，复用质量分析的分层 prompt 簇抽样，报告 95% 描述性区间及各组中位数/IQR。五质量指标按原计划使用 99% 双侧区间；配对簇采样携带三个 seeds 和两方法，不把视频/帧当独立 prompt。

每个 worker 真正加载前两次核验空闲、只暴露所用 GPU UUID；运行时若有额外 PID 或无法可靠查询，只中止自己的 worker。完整失败和重试保留，按原输入/配置重试整对并使用唯一有效 attempt。自己项目内的文件锁不构成服务器全局预约。预计新增源噪声、视频两份、日志和统计总预算不超过 5 GiB；共享模型与软件环境保持原样。

全部 96 条视频通过帧数/尺寸/FPS、有限值及双解码核查后，六项原版 VBench 函数在现有离线环境完成 576 个分数。按 prompt 分块保存，保留原值和一次归一化值。检查完整性、越界、常量/饱和与运动变化；不以人工质量评分补充或筛除样本。
