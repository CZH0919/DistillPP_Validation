本轮任务是从研究目标审视评测设计。仅查阅官方资料、现有源码/结果，并做本地 CPU 描述统计；未运行新视频生成、GPU 评测、下载权重或安装依赖。正式 S2 数据、配置、统计与未进入 S3 的状态不变。

**2026-10-17 后续决定：先以现有资源身份、固定源码及实际运行记录明确生成调用契约，再修正官方 prompt—指标对应关系。**该核查已完成且未发现已知调用错误；当前具体协议以 `Project_Plan/OFFICIAL_QUALIFICATION_V2.md` 为准。下文保留本次复盘事实，第 5 节为历史候选建议，不构成补充动作评测或重跑旧 16 条扩写实验的执行指令。

## 1. 官方“highest quality”能追溯到什么

- LightX2V 的[模型格式说明](https://lightx2v-en.readthedocs.io/en/latest/getting_started/model_structure.html)使用了该措辞，但没有为这句话给出评测指标、prompt 列表或当前 T2V 原版与四步 PT 学生的定量比较。
- 其链接的[Benchmark 正文](https://github.com/ModelTC/LightX2V/blob/main/docs/EN/source/getting_started/benchmark_source.md)是 I2V 的耗时、显存、加速比与示例视频比较。不能把它当成当前 T2V 模型组合的客观质量证据。所用[学生模型卡](https://huggingface.co/lightx2v/Wan2.1-T2V-14B-StepDistill-CfgDistill)也未列出这样的定量师生对照。
- 进一步查阅 [Wan 技术报告第 4.5–4.7 节](https://arxiv.org/html/2503.20314v1#S4.SS6)：其质量论证包含内部 Wan-Bench、完整 VBench 与独立人工比较。Wan-Bench 覆盖动态质量、图像质量、指令遵循三大类、14 个细项，每个候选模型报告 1,035 个样本；包含动作执行、物理合理性、人体伪影、空间关系等能力。论文中的 VBench 表报告 Wan14B 总分 86.22%。这些比较对象不是我们当前的 LightX2V 学生。此次未找到内部 Wan-Bench 完整 prompt 清单、全部专用评测器与可直接复现的官方发布入口；不能将论文描述当作已获得评测资源。

VBench 的[总分实现](https://github.com/Vchitect/VBench/blob/master/scripts/constant.py)把 7 项质量与 9 项语义维度分别聚合，总分质量/语义权重为 4:1；dynamic_degree 也正向参与其质量分。我们将 dynamic_degree 单独作为护栏、保留六项逐维结果，属于不同评价问题，不能把官方总分高直接换算成我们的五项质量优势。继续尊重“不加入人工视频质量评分、不把动态程度越高当越好”的约定。

## 3. 当前面板的主要不足是任务覆盖与指标对应

依据 [VBench prompt 协议](https://github.com/Vchitect/VBench/blob/master/prompts/README.md)以及固定版本的 `VBench_full_info.json`，不同维度使用不同任务集合，而非对任意同一小面板统一计分后替代官方全套测试。

| 官方维度组 | 专用 prompt 数 | 本轮 16 条中来自该集合的数量 |
|---|---:|---:|
| 主体一致性、运动平滑度、动态程度 | 共用 72 条 | 4 条，均为动物动作 |
| 成像质量、美学、文本视频一致性 | 共用 93 条 | 4 条，本轮归为场景类 |
| human_action | 100 条 | 8 条，但本轮没有测对应动作指标 |

本轮对全部 16 条统一计算六指标，是可解释的自定义受控比较；数据没有因此作废。但它不是官方维度匹配的缩小复现。原始短 prompt 本来就是合法的官方测试文本，不能笼统说“prompt 错了”。真正的问题是半数题目要求人物动作，却主要用帧级外观、时序相似性及粗粒度语义代理判断，动作识别本身未直接测量。

当前六项有实际价值，但不能覆盖动作是否按描述发生、复杂关系、物理合理性、细粒度形体错误等全部目标。官方 `human_action` 也只是动作识别代理，不等于完整动作执行或物理正确性的通用判据；若后续引入，必须说明这一限制。不要为制造教师优势而堆加指标或改用某个总分。

| 教师/学生动态标记 | 配对数 | 主体一致性均值差 T−S |
|---|---:|---:|
| 0 / 0 | 16 | −0.007109 |
| 0 / 1 | 3 | +0.000920 |

学生的一致性均值优势在双方均被判为动态的样本中仍存在。“学生运动少”只能作为可能的部分解释，不能当作全部原因。二值动态标记也不意味着双方运动幅度相等。不能据此宣称当前指标无效或推翻原资格结果。

## 5. 建议的研究推进顺序（待确定方案，未执行）

研究目的仍是：教师在有科学意义的目标能力上已有优势，有限推理纠偏改善学生该能力，同时保留相对完整教师的实际速度优势。控制变量保证比较可解释，但还需要目标能力与测量工具匹配。

1. 先确定具体质量缺口及对应任务。当前最有依据优先讨论的是动作语义/运动中的质量，以及丰富视觉描述下的成像与细节；这是假设，不是已证实的教师优势。六项原指标保留，不把动态程度改成质量目标，不加入人工视频评分。
2. 优先利用已有视频。若选择人物动作能力，可提议对已有 8 条动作 prompt、3 seeds、两组共 48 条视频补充官方动作识别指标，作为探索性分析；需另核对资源，不能默认为已安装或自动下载，也不把该事后新增指标直接用于改判 S2。
3. 单独检验 prompt 表述的影响。可在当前 16 条语义上对照公开扩写文本，保持两组同一文本、源噪声、分辨率和采样配置。复用已有 96 条短文结果，仅新增扩写条件的 96 条视频；这是低重复成本的诊断提议，不是运行授权。记录生成文本与评测文本，统一用原任务描述作为跨条件语义锚点，避免 ViCLIP 32-token 上限把长文静默截断后冒充完整评分。
4. 不同时改 prompt、分辨率、shift 与指标后只报告胜出结果。当前先检验评测设计；720P 是官方条件差异的证据，不意味着现在立即升级分辨率。如果诊断支持某个具体质量缺口，再冻结独立新 prompt 面板与主要指标，确认教师优势后由研究者决定是否进入 S3。仍未建立时重新考虑模型组合或目标能力，不以调参到胜出为任务。

本文件不改变实验计划中的既有数据与统计结论。下一步需要确定的是研究目标与新验证协议，而非继续扩大权重核验工作。
