## 2. 选择与边界

| 方案 | 三库 prompt 数 | 每 prompt seeds | 配对数 / 两组视频 | 取舍 |
|---|---:|---:|---:|---|
| 旧 64×3 | 32/16/16 | 3 | 192 / 384 | 当前生成预算较大 |
| **采用 64×1** | **32/16/16** | **1** | **64 / 128** | 保留全部文本覆盖；不估计跨 seed 稳健性 |
| 不采用 32×2 | 16/8/8 | 2 | 64 / 128 | 同样成本，但后三项质量各只剩 8 个不同 prompt；可观察两次噪声差异 |
| 不采用 32×1 | 16/8/8 | 1 | 32 / 64 | 文本和 seed 覆盖均更少，仅适合较弱的预观察 |

选择基于本轮固定预算内优先保留不同 prompt 的设计判断，不是依据 H1 的正向分数挑文本，也没有足够先验方差做可靠功效承诺。使用原先冻结种子列表首项 2026101901，H1 seed 2026101900 排除；原 prompt CSV 完全不变。按官方库分别计算 224 个值：主体 64、动态 64、背景 32、场景 32、多物体 32（均为两模型合计）。

统计：每个 prompt 仅一个配对差，库内以 prompt 对 bootstrap 20,000 次；四项质量仍为 98.75% 名义 Bonferroni 区间，动态 95%。固定 seed 条件下有 32/16/16 个 prompt 单元，不能当作 64 个独立噪声重复；不保证功效、精确覆盖或跨 seed 优势。结果不确定如实报告，不自动加样直到显著。研究者决定效应大小和指标取舍；资格成立且研究者确认后才进入迁移，同一 64×1 面板沿用至 H4。
